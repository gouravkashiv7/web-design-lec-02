# Lab and Homework: College Student Profile

**Lecture 02** · HTML only · Type it, don't paste it

## What you are building

`profile.html`: a one-page profile that the browser never has to guess about.

## Lab (in class)

| Part | Must include |
|---|---|
| Name | One `h1` with your full name |
| Bio | A paragraph: course, college, one fun fact |
| Skills | A `ul` with at least three items and `id="skills"` on its heading |
| Hobbies | A list of your hobbies. Decide: `ul` or `ol`? |
| Links | At least three: an email link, an external site, and a link back to `#skills` |

## Homework (due before Lecture 03)

Build on your lab file. Your page should have:

- [ ] Two lists: one `ul` and one `ol`
- [ ] Five links, including one to a `#section` on the same page
- [ ] Headings in outline order: one `h1`, then `h2`s
- [ ] Clean indentation and at least one comment
- [ ] Zero errors at [validator.w3.org](https://validator.w3.org/#validate_by_upload)

## Submit

`profile.html` · a screenshot of the validator showing zero errors · one bug-log entry (expected / actual / cause / fix)
